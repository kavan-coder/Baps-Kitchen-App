# Security Policy

## Supported Version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Instead, report them privately to the repository owner through GitHub or contact the maintainer directly. Include:

- A clear description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any suggested mitigation, if available.

The maintainer will acknowledge the report, investigate it, and coordinate a fix where appropriate.

## Sensitive Configuration

Do not commit private keys, access tokens, service-account credentials, or unredacted production configuration. If sensitive information is accidentally committed, revoke or rotate it promptly and report the exposure privately.
